# LifeOS Gym SVG V1

These 22 files are byte-for-byte copies of the adjusted SVG resources from:

`artifacts/gym-visual-proposals/LifeOS_Gym_SVG_encuadres_ajustados_V1/ajustados/`

Only filenames were normalized for stable local URLs. Geometry, paths, viewBox values,
embedded text and colors were not changed. The original and adjusted source packages stay
under `artifacts/gym-visual-proposals/LifeOS_Gym_SVG_encuadres_ajustados_V1/`.

Licensing is pending verification for every resource before public deployment.
`adjustable-bench.svg` retains its embedded Noun Project attribution and is tracked as
`pending-attribution`. `pull-ups.svg` (`DOMINADAS.svg` in the source package) also needs a
specific rights review because it combines earlier resources.
